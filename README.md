# Sounding Room

Interpret Vertical Electrical Soundings (VES) in the browser.
For Nigerian groundwater surveys that still depend on VES software
made for Windows 95.

> **Status:** started 2026-11-24 for the
> [Kiroween 2026](https://kiroween.devpost.com/) hackathon (Resurrection
> category). Built with [Kiro](https://kiro.dev). Work in progress: there is
> no app code yet.

## Data

`data/basiri/` holds 30 real VES stations from Basiri, Ado-Ekiti, Nigeria
(Aizebeokhai et al., 2018, CC BY 4.0), with the raw readings and the
authors' WinResist results. See [data/basiri/README.md](data/basiri/README.md).

## Disclosure

The author worked on VES tools before (ves-field-agent,
ves-label-benchmark). No code from them is used here. This repository was
started on 2026-11-24, during the Kiroween submission period.
